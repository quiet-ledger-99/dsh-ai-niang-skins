## 2. 统一设计与实施原则

角色衍生设计先盘点可取得的原立绘、视觉卡、表情母版等，区分原立绘与派生参考，再选择与目标结构相关的图片。没有把一张生成稿或视频截图当作角色全部依据，也没有声称取得每个角色所有历史版本。

五套都围绕DSH的真实结构制作：全局导航、工作区/会话列表、消息阅读、输入卡、模型与权限工具、询问/审批、账户菜单和设置。品牌与输入框承担主要装饰，文字与操作区域保留留白；小窗口下优先保住工作区和可点击控件。

图像素材使用用户提供的原设与已有素材，按需要用内置imagegen派生。制作代码、完整提示词、引用图片和实际采用资源分别保留；本会话没有在本机运行大模型推理。视频由既有制作流程或用户另行交回的Grok Bot成片提供，本报告不把上游视频生成成本归为本会话的免费调用。

## 3. 各主题完成的工作

### 3.1 Gemini娘 · 星光工作台

视觉方向为深靛星夜、紫蓝纸艺、指定四芒星和彩虹缎带，保留猫耳、猫尾及原角色色彩识别。把原有主题素材重新适配为DSH工作区、会话、输入和详情结构，重算装饰边缘与可用内容区。

主要完成：消息区配色与背景可见性调整；品牌图形与DeepSeek字样错位修正；四芒星点缀；导航、工作区、底部与账户菜单图标配套；输入框纸艺边饰；询问/审批整卡磨砂底板及命令区、按钮层次。当前清单声明的是PNG插画，动效通过既有图片/CSS素材实现，没有把它写成MP4背景。

工程包含独立交互设计稿与实施/安装记录。早期网页稿中的示例交互、示例回复及审批卡只展示设计，不代表调用过真实模型或做过真实授权。

### 3.2 千问娘 · 月下青瓷

从角色的花枝金线、蓝白材质、菱形宝石与流苏提取青花、瓷釉牡丹、锦缎、金络与垂珠的设计语言。品牌牌匾、输入框和身份装饰形成一组，侧栏用低对比刺绣，不沿用Gemini的猫耳四芒星或彩虹纸艺。

主要完成：眨眼过渡与轻动态背景；黑屏/播放来源修正；绘制品牌框与输入框，并对输入框中段做可拉伸适配；新会话、功能图标和侧栏纹样升级；设置页文字/卡片对比调整。保留当前0.2.1视频作为0.3.1皮肤的动态媒体，没有因为UI版本变化而改错媒体文件名。

历史记录包含原生首页、输入/清空、菜单、紧凑侧栏等检查；询问/审批完整外观有离线设计预览，未把它概括为已经触发真实权限请求。

### 3.3 ChatGPT娘 · 云上银庭

构图采用云上银庭、星空与白色龙系角色，区别于千问场景。按用户明确的色彩要求，界面以珍珠白、黑色细边纹为主，银色编结与鳞纹连接组件，紫色仅少量点缀；没有以眼睛颜色为由让金紫成为主色。

主要完成：品牌牌匾、龙翼/鳞纹输入框、侧栏与功能图标深化；修复工作区被装饰挤压的问题；接入用户确认的v5c动态背景，保留裙摆、龙翼、鳞尾与云层/花枝/星空环境的动态；处理设置阅读对比和输入区结构。

本次发现当前安装的patches-inkwhite.css比10月31日交接和本机旧工程多了Coding Bot标注的2026-11-01手机工作区补丁，包括窄屏列表空间、文字、滚动及点击相关样式。清单仍为0.4.2。本次已将当前完整CSS同步到入库副本的skins和对应source-projects/skin镜像，另存差异文件，保留原作者注释；原始本机工程未被改写。文件见docs/current-overrides/。

历史“偶发背景停播”诊断未复现用户故障，曾观察到重新应用后持续跨循环出帧，根因仍未定；该记录没有产生一个已根治的新播放器版本。不能把本次报告写成永久修复了所有停播场景。

### 3.4 DeepSeek娘 · 澄潮绮窗

根据鲸系蓝白角色设计海底书房、环形海窗与桌前交流的场景。用户指出原托腮图坐卧关系不明后，保留场景，改为明确坐正、一手搭书、一手扶杯的母图v3，露出椅背与扶手，分开鲸尾和裙摆。随后编写动画制作报告、归档母图与提示词，由用户交回Grok Bot视频v4。

主要完成：v4视频接入；修正空会话顶部58/40px偏移造成的静态重复条、欢迎标题遮额头与HARNESS字样对比；进一步升级到0.2.0，新增六张绘制素材：两张12枚图集、鲸尾贝壳输入框、珍珠牌匾、藏书封面侧栏、决策面板边框。共24枚配套器物图标，涵盖常用导航、工作区、底部与控件素材，Tripo入口也有配套适配。

同时补齐旧会话的磨砂阅读底板，修复完成消息缺少streaming-body标记时正文直接叠在插画上的情况；为工作区/模式选项补底衬；保持设置文字与工作区空间可用。首页、真实旧会话、导航和设置已做原生检查；菜单图标及询问/审批完整外观另有离线预览。视频未重压、未增加倒放或交叉淡化。

### 3.5 Grok娘 · 绯月邀约

按用户要求采用血族气质，保留金发双马尾、蓝眼、精灵耳、月冠、黑金礼裙、酒红衬里、杯与单把X型撑架战斧。经历大厅、扶栏、站姿等候选后，采用用户认可的窗边近景“绯月邀约”母图v4，避免与其他主题重复的单侧站姿构图。

主要完成：母图与动画制作交接；接入Grok Bot v3正向主片与回程桥接；0.2.0新增两张12枚绘制图集，以及黑金珐琅牌匾、雕金丝绒输入框、玫瑰侧栏材质，共五张素材。图标、输入框、品牌、菜单与设置配色形成黑金酒红体系，保留清楚的文字中心和工作区空间。

## 5. 实装、切换与验收范围

五套都采用skinManifestVersion: 2，清单声明CSS、补丁样式、封面和背景媒体；当前五套均没有声明客户端hooks。Python/JS制作脚本与预览脚本属于工程侧，不需要装进DSH才能使用主题。

切换入口：左下角头像/账号菜单 → 设置 → 皮肤 → 对应卡片“试穿”或“应用”。使用现有Skin Center热切换与选择持久化，未另装重复的切换插件。五套已在同一个原生列表中逐一切换过；后续DeepSeek0.2为同ID的视觉资源与样式升级。

主要原生环境记录为macOS、DSH Desktop 0.2.1-rc.5、Skin Center 0.4.8；较早记录可能使用0.2.1-rc.3。不能把历史设计稿的尺寸检查、隔离宿主检查、正式原生界面检查及模型事件验收混为一项。

已执行的验收与证据按主题保存。尤其保留以下边界：

- 多套设计页检查过桌面/窄窗口，DeepSeek/Grok另保留1280×720离线设计预览；这些不代表全部移动端与远端桌面场景都已验收。
- ChatGPT当前包含已存在的手机补丁，本次仅纳入快照，没有重新做手机实机验收。
- 询问/审批外观主要依据离线示例；没有为验收主动发起收费模型调用或真实权限命令。
- 部分第三方插件内部图标仍可能由宿主绘制，不宣称所有插件页面都已定制。
- 更新同ID媒体清单时GUI可能缓存旧入口，需以真实新画面为准；DeepSeek的旧媒体缓存曾在空闲界面重开后刷新。磁盘复制成功不是界面验收证明。

本轮报告整理只读现有安装与工程文件，生成上传副本和安装ZIP；没有重新做五套全量UI/视频验收，也没有修改正式皮肤、选择状态、核心、插件或profile。
